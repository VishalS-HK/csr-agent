# Return Processing Policy

*Fictional policy for a synthetic online electronics retailer. Invented for this project.*

## Section 1: Requesting a return

A customer may request a return within 10 days of delivery. Only delivered orders can be returned.

## Section 2: Return shipping

After a return is requested, the customer sends the item back. While it is on its way, the return status is "in transit".

## Section 3: Receiving a return

A return is marked "received" when the item arrives at the warehouse. The date it arrives is recorded.

## Section 4: Inspection

Received items are inspected within 3 business days. The result is either "passed" or "failed".

- **Passed:** the item is eligible for a refund under the Refund Eligibility Policy, Section 3.
- **Failed:** the item is not eligible for a refund. It is sent back to the customer.

## Section 5: Disputed inspections

If a customer disagrees with a failed inspection, the case is escalated for human review.
